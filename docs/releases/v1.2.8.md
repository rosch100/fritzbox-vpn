## What's changed since v1.2.7

- **Fix (#64):** Home Assistant 2026.9 no longer accepts the deprecated `via_device` parameter on `DeviceInfo`. VPN connection devices now use the parent Fritz!Box device ID through `via_device_id`.
- **Fix (#65):** In Graceful availability mode, entities stay available after a single failed poll while coordinator data remains trusted.

### 🇩🇪 Was ist neu seit v1.2.7

- **Fix (#64):** Home Assistant 2026.9 akzeptiert den veralteten Parameter `via_device` an `DeviceInfo` nicht mehr. VPN-Verbindungsgeräte verwenden jetzt die ID des übergeordneten Fritz!Box-Geräts über `via_device_id`.
- **Fix (#65):** Im Verfügbarkeitsmodus Graceful bleiben Entitäten nach einem einzelnen fehlgeschlagenen Poll verfügbar, solange die Coordinator-Daten noch vertrauenswürdig sind.

**Full Changelog:** https://github.com/rosch100/fritzbox-vpn/compare/v1.2.7...v1.2.8
