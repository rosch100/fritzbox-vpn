## What's changed

- **Fix (#64):** Home Assistant 2026.9 no longer accepts deprecated `via_device` on `DeviceInfo` (RuntimeError via `report_usage`). VPN connection devices now link with `via_device_id` from the parent Fritz!Box `DeviceEntry.id` stored at setup. Builds without `via_device_id` keep the identifier-tuple parent link.
- **Fix (#65):** In Graceful availability mode, entities no longer go `unavailable` after a single failed poll. Availability follows trusted coordinator data (`connection_available` / `_attr_available`) instead of `CoordinatorEntity.last_update_success`.

### 🇩🇪 Deutsch

- **Fix (#64):** Home Assistant 2026.9 lehnt das veraltete `via_device` an `DeviceInfo` ab (`RuntimeError` über `report_usage`). VPN-Verbindungsgeräte hängen jetzt über `via_device_id` an der Parent-`DeviceEntry.id` der Fritz!Box aus dem Setup. Builds ohne `via_device_id` behalten den Identifier-Tuple-Parent-Link.
- **Fix (#65):** Im Verfügbarkeitsmodus Graceful werden Entitäten nach einem einzelnen fehlgeschlagenen Poll nicht mehr `unavailable`. Die Verfügbarkeit folgt den vertrauenswürdigen Coordinator-Daten (`connection_available` / `_attr_available`) statt `CoordinatorEntity.last_update_success`.
