## What's changed since v1.2.9

- **Fix (#75):** Editing a VPN profile on Fritz!OS can assign a new connection UID without a reboot. The integration keeps one entity set per connection name and removes older same-name devices after a successful poll.
- During an outage the connection list can be incomplete. Older same-name devices stay until recovery has finished, so a short list does not delete them.

### 🇩🇪 Was ist neu seit v1.2.9

- **Fix (#75):** Beim Bearbeiten eines VPN-Profils kann Fritz!OS eine neue Verbindungs-UID vergeben, ohne dass die Box neu startet. Die Integration behält pro Verbindungsname einen Entitätssatz und entfernt ältere Geräte gleichen Namens nach einem erfolgreichen Abruf.
- Während einer Störung kann die Verbindungsliste unvollständig sein. Ältere Geräte gleichen Namens bleiben, bis die Recovery beendet ist.
